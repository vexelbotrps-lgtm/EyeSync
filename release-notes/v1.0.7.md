## EyeSync 1.0.7

- Voice typing now treats every recognised phrase as ordinary dictated text.
- Removed spoken editing actions such as “delete that”, “new line”, and spoken punctuation.
- Voice typing still starts and stops with the one-second both-eyes-closed gesture or the visible Stop button.
- Left click, right click, voice typing, and Command Panel controls are documented together on the website’s Controls page.

The setup includes Python and all required runtime models. Windows 10 or 11, a webcam, and a microphone are required.
