## EyeSync 1.0.8

- Starts paused; click Resume to enable control.
- Closing the main window exits EyeSync and the Command Panel.
- Removed the cropped footer buttons and corrected the click status text.
- One-second bilateral eye hold toggles voice typing, using adaptive open-eye measurements.
- Tilt left to scroll up or right to scroll down; straighten to stop. Scrolling is disabled while paused and holds the cursor steady.
- Preserved the original cursor speed.
- Main window, Command Panel and taskbar use the shared EyeSync icon.

Python 3.15.2 and runtime models are bundled. No separate Python installation is needed.
