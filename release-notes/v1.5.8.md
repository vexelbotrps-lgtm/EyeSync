# EyeSync 1.5.8 for Windows

This is an update to the downloadable Windows application, not the browser demo.

- **Fewer false clicks while one eye is reopening.** A click can no longer be armed merely by a high closure score on one eye averaged with an already-open other eye. Both eyes must still participate in the closure when the tick sounds.
- **Asymmetric blinks remain supported.** One eye may close less than the other, as before; deliberate blinks and winks are covered by regression tests.
- **Verified executable packaging.** The Windows regression suite runs before packaging, again inside the built `EyeSync.exe`, and once more after a clean test install without shortcuts or registry registration.

## Downloads

- **EyeSync.exe** — the normal Windows 10/11 download and self-installer.
- **EyeSync-1.5.8.zip** — the optional Python-source package for developers.

The website's `downloads/latest.json` contains the exact executable byte size and SHA-256. No application can be guaranteed perfect for every face, camera or environment; use **Calibrate** for your own setup and report reproducible problems.
