# EyeSync 1.5.9 for Windows

This update improves the downloadable Windows application's blink calibration using public-video evaluation. It does not change the browser demo's head-control engine.

- **Blink timing is fitted to you.** Calibration now measures the duration of three slow closures as well as their depth. It sets the click tick to 90% of the median detected hold, bounded to 0.30–0.65 seconds, so the timing stays below what you demonstrated. An explicit `--min-blink` setting still takes precedence.
- **Recalibrate to enable the improvement.** Follow the guide and, if comfortable, keep your eyes closed for about 0.7 seconds for each of the three slow blinks. Uncalibrated behavior remains at the existing 0.30-second default, and shorter demonstrated closures retain a shorter accessible tick.
- **Tested on unseen public speakers.** In the frozen held-out GRID replay (speakers 9–16, 100 minutes), the representative 0.60-second calibrated setting reduced false clicks from **147 to 16 (89.1%)**. Real-appearance extended-hold sensitivity was **639/640 under both old and new timing**, with no increase in right-clicks, gestures or scroll notches. Development used a separate group, speakers 1–8.
- **Verified Windows packaging.** The complete source regression suite runs before packaging, again inside the built `EyeSync.exe`, and again after a clean test install without shortcuts or registry registration.

## Downloads

- **EyeSync.exe** — the normal Windows 10/11 download and self-installer.
- **EyeSync-1.5.9.zip** — the optional Python-source package for developers.

The website's `downloads/latest.json` contains the exact executable byte size and SHA-256 after those assets are verified. GRID readers were not deliberately operating EyeSync, and public-video replay cannot guarantee perfection for every person, camera, lighting condition or accessibility need. The aggregate evaluation and attribution are in `experiments/grid/` and `EyeSync/tools/DATASETS.md`.
