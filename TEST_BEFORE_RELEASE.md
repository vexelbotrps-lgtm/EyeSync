# Release gate

Before publishing any new EyeSync version, let the user test the local changes
and obtain their confirmation that the tested build is ready to release.

The user tested the local changes and requested release of the latest version.
Version 1.0.8 includes a one-second eye hold, startup paused with Resume,
window X closes EyeSync and Command Panel, footer removed, head-tilt scrolling,
original cursor speed, and shared window/taskbar icons.
